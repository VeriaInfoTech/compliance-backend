## 📌 Important Notes

⚠️ **HTML2Canvas & jsPDF Scripts**
- Must be added to index.html BEFORE component use
- Check console for "html2canvas is not defined" error
- Both scripts required for PDF export to work

⚠️ **Tailwind CSS**
- Component uses Tailwind for all styling
- No custom CSS files required
- Ensure Tailwind is properly configured in your project

⚠️ **Backend API Response**
- Component expects specific data structure
- See REPORT_DATA_SCHEMA.md for requirements
- Missing fields will be handled gracefully

⚠️ **Persian/RTL Display**
- Component has `dir="rtl"` on root element
- Check parent containers don't override direction
- Persian numbers are automatic (can be disabled)
